¿Te imaginas ser un mariscal de campo para dirigir tu propia batalla?

Dispones de un ejército con el cual tendrás que cumplir una serie de objetivos hasta llegar al jefe final. 

Utiliza los números del 1 al 5 para movilizar batallones de cualquiera de los 5 tipos de unidades disponibles, pero ojo, asegúrate de combinarlas bien para no perder las mejores en los primeros combates.

Por supuesto, no olvides proteger al mariscal! Muévete por el campo con las flechas del teclado y utiliza las letras J, K y L para atacar, protegerte y disparar.

GUÍA DE EJECUCIÓN

1. Clona el repositorio.

2.Despliega el servidor: npx http-server -p 3026

3. Abre el localhost con ese puerto, ¡y que comience la batalla! (Puedes cambiar el número si lo deseas)
